This project is an assignment of "Hypermedia Application" course at Politecnico di Milano during the academic year 2023/2024.
The goal is to develop the front-end of a dynamic website, which loads its variable content from a database. The interface must respect the good practices for UX/UI and usability. Its development includes the employment of Nuxt and Vue.
